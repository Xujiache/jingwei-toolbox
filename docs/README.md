## 维护规则

- `api/openapi.json` 是服务端接口字段、路径、状态码和认证方式的唯一基线。
- 本地工具不依赖后端接口，但仍需维护独立的工具契约和可重复验收步骤。
- 任何接口变更必须同时更新后端控制器/测试、前端类型或请求封装、管理后台调用和本目录文档。
- 文档中的“计划”“待确认”不能当作已实现功能；交付报告必须区分计划、实现、验证和未验证内容。
- 每次发布记录文档版本、API 版本、数据库迁移版本和回滚方式。
- 每个工具契约必须通过 `python scripts/verify-tool-contracts.py`，再进入后端、客户端和后台实现。
